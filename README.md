# Dexter Store — หน้าเว็บ + ฐานข้อมูลบนเซิร์ฟเวอร์

## รันแบบมีฐานข้อมูล (แนะนำ)
ต้องมี Node.js 18 ขึ้นไป (ไม่ต้องติดตั้งแพ็กเกจเพิ่ม)
```
ADMIN_PASSWORD=รหัสแอดมินของคุณ node server/server.js
```
แล้วเปิด http://localhost:3000 — เซิร์ฟเวอร์ตัวเดียวเสิร์ฟทั้งหน้าเว็บและฐานข้อมูล
- ข้อมูลทั้งหมดอยู่ในโฟลเดอร์ `data/` (db.json + สำรองอัตโนมัติ db.json.bak) สมาชิก ยอดเงิน สต็อก คำสั่งซื้อ ตั้งค่าร้าน ใช้ร่วมกันทุกเครื่อง
- เซิร์ฟเวอร์เป็นผู้คิดเงิน ตัดสต็อก ตรวจโค้ด/ส่วนลด หน้าเว็บแก้ตัวเลขเองไม่ได้ รหัสผ่านเก็บแบบ hash (scrypt) รหัสสต็อกส่งให้ลูกค้าเฉพาะตอนซื้อสำเร็จ
- เข้าหลังบ้าน: กด "เข้าสู่ระบบ" ใส่รหัสแอดมิน (ช่องชื่อเว้นว่างหรือพิมพ์ admin) — เปลี่ยนรหัสได้ที่ ตั้งค่าเว็บ
- ตัวแปร: `PORT` (3000) · `ADMIN_PASSWORD` (ใช้ตอนสร้างฐานข้อมูลครั้งแรก ไม่ตั้ง = admin1234) · `DATA_DIR` (ที่เก็บข้อมูล) · `ALLOW_ORIGIN` (ถ้าหน้าเว็บอยู่คนละโดเมน แล้วตั้ง localStorage `dx_api` เป็นที่อยู่เซิร์ฟเวอร์) · `TZ_OFFSET` (เขตเวลา ค่าเริ่มต้น 7)
- สำรองข้อมูล = คัดลอกโฟลเดอร์ `data/` · กู้คืน = วางกลับแล้วรันใหม่
- ขึ้นโฮสต์ (VPS / Render / Railway ฯลฯ): สั่ง `npm start` และต้องใช้ **ดิสก์ถาวร** ชี้ `DATA_DIR` ไปที่ดิสก์นั้น ไม่งั้นข้อมูลหายตอนรีสตาร์ท ควรใช้ HTTPS เสมอ
- รับซองทรูมันนี่อัตโนมัติ: หลังบ้าน > ระบบรับเงิน ใส่เบอร์ TrueMoney Wallet แล้วเปิด "แลกซองอัตโนมัติ" (ใช้ endpoint ไม่เป็นทางการของ TrueMoney ทดสอบด้วยซอง 1 บาทก่อน) สลิป PromptPay ให้แอดมินอนุมัติเอง

## รันแบบไม่มีเซิร์ฟเวอร์ (ทดลอง)
เปิด `index.html` หรือ `dexter_store.html` ตรงๆ จะเก็บข้อมูลในเบราว์เซอร์ของเครื่องนั้นเท่านั้น ไม่แชร์ข้ามเครื่อง และไม่ปลอดภัยพอสำหรับขายจริง

## โครงสร้างไฟล์
```
index.html            โครงหน้าเว็บ
css/style.css         ธีมและหน้าตา (รองรับมือถือ)
js/core.js            ตัวช่วย ข้อมูล ธีม header/nav modal
js/auth.js            สมัคร / ล็อกอิน / ยืนยันไม่ใช่บอท
js/shop.js            หน้าแรก สินค้า หน้ารายละเอียด สั่งซื้อ เติมเงิน
js/profile.js         โปรไฟล์ ประวัติ ตัวกรองวัน
js/admin.js           หลังบ้านทั้งหมด
js/music.js           ปุ่มเพลง + อัปโหลดเพลง
js/api.js             โหมดเซิร์ฟเวอร์ (คุยกับฐานข้อมูลกลาง)
js/main.js            เริ่มทำงาน
server/server.js      เซิร์ฟเวอร์ + ฐานข้อมูล + เสิร์ฟหน้าเว็บ
data/                 ที่เก็บข้อมูล (สร้างอัตโนมัติ)
```
ลำดับโหลดสคริปต์ใน index.html สำคัญ (core → auth → shop → profile → admin → music → api → main)
