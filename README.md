# Dexter Store — โครงสร้างไฟล์

```
index.html            โครงหน้าเว็บ (มีแค่ตัวหน้า + เรียกไฟล์ css/js)
css/style.css         ธีมและหน้าตาทั้งหมด
js/core.js            ตัวช่วย, ข้อมูลร้าน (localStorage), session, ธีม, header/nav, modal
js/auth.js            สมัคร / เข้าสู่ระบบ / ยืนยันไม่ใช่บอท
js/shop.js            หน้าแรก, แบนเนอร์, สินค้า, ซื้อ, เติมเงิน
js/profile.js         โปรไฟล์, ประวัติ, ตัวกรองวัน
js/admin.js           หลังบ้านทั้งหมด (สินค้า+สต็อก, หมวด, สมาชิก/ยศ, ระบบรับเงิน, ตั้งค่า)
js/music.js           ปุ่มเพลงพื้นหลัง + ตัวอัปโหลดเพลงในหลังบ้าน
js/sync.js            ซิงค์ข้อมูลหลังบ้านไปเครื่องอื่น (ผ่านเซิร์ฟเวอร์ของคุณ)
js/main.js            เริ่มทำงาน
server/               เซิร์ฟเวอร์ (Node.js 18+): /verify รับซองทรูมันนี่ และ /state ซิงค์ข้อมูลหลังบ้าน
```

- ลำดับโหลดใน index.html สำคัญ (core → auth → shop → profile → admin → music → sync → main) ห้ามสลับ
- เปิด index.html ได้เลย ไม่ต้องติดตั้งอะไร
- ขึ้นโฮสต์: อัปโหลดทั้งโฟลเดอร์ (ยกเว้น server/) ไปที่ Netlify / Cloudflare Pages / GitHub Pages
- เข้าหลังบ้าน: กด "เข้าสู่ระบบ" แล้วใส่รหัสแอดมิน (เริ่มต้น admin1234 เปลี่ยนที่ ตั้งค่าเว็บ)

## ซิงค์ข้อมูลหลังบ้านไปเครื่องอื่น
1. ขึ้นเซิร์ฟเวอร์: `ADMIN_TOKEN=รหัสลับยาวๆ ALLOW_ORIGIN=https://โดเมนร้าน node server/dexter_payment_server.js`
   (ควรใช้โฮสต์ที่มีดิสก์ถาวร หรือตั้ง DB_PATH ไปยังโฟลเดอร์ถาวร ไม่งั้นไฟล์ sync_db.json อาจหายตอนรีสตาร์ท)
2. เครื่องหลัก: หลังบ้าน > ตั้งค่าเว็บ > ซิงค์ข้อมูล ใส่ URL + รหัสซิงค์ แล้วกด "บันทึกขึ้นเซิร์ฟเวอร์" (ติ๊กอัตโนมัติได้)
3. เครื่องอื่น: เข้าหลังบ้านด้วยรหัสแอดมินของเครื่องนั้น ใส่ URL + รหัสซิงค์ แล้วกด "ดึงข้อมูล"
- ข้อมูลที่ซิงค์ = ทั้งหมด (สินค้า สต็อก สมาชิก ตั้งค่า ประวัติ รหัสแอดมิน) ใช้ "เขียนทับทั้งก้อน" ไม่รวมแบบละเอียด ห้ามแก้พร้อมกันสองเครื่อง
- ลูกค้าทั่วไปไม่ได้ซิงค์ และไม่เห็นเมนูนี้
